## Upstream code

This package builds directly on GravitationalWaveData.jl and GravitationalWaveforms.jl, both
GPL-3.0-or-later and both containing code derived from GPL projects (GWpy, LALSuite and pySEOBNR);
their NOTICE files give the details. Its GPU kernels re-express those packages' waveform and detector
routines.
